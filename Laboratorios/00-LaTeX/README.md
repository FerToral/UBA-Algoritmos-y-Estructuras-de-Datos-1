# Laboratorio00 · LaTeX y especificación

Documento de práctica con portada, índice, producto factorial, contrato de factorial, cuantificadores, predicados sobre secuencias y suma condicional. El último apartado practica índices y notación de un promedio cuadrático como ejemplo adicional.

Abrir `main.tex` en un editor LaTeX y compilar dos veces para actualizar el índice. Sólo utiliza paquetes habituales de una distribución TeX; las macros pequeñas de notación se definen en el documento. No depende de logotipos, datos personales ficticios ni plantillas externas.

El predicado universal sobre una secuencia vacía es verdadero; el existencial es falso. La suma vacía vale cero. La especificación de factorial incluye el caso0, aunque la definición inicial del producto se presente para positivos.

La guía histórica del taller00 y sus macros/portada originales se conservan en el archivo de la cursada. Esta versión usa notación y portada propias para estudiar los mismos conceptos sin depender de la redistribución de esos auxiliares. Fuente: colección AyED1 1C2022, guía con pie1C2021.
